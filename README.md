# 见微 · VISTA

一个优先为 iPhone 设计的私人 AI 识图与聊天网页。使用你自己的 API 中转站、密钥和模型；无需 App Store 或苹果开发者账号。

## 已实现

- 图片 + 文字、多图、相册选图、拍照、粘贴图片、发送前预览。
- 多轮聊天、新建/切换/重命名/删除对话、复制回复、重新生成、停止生成。
- 提示词收藏与搜索，支持新建、编辑、删除；调用时追加到输入框。
- 自定义 API Key / URL / 模型名、可选系统提示词、连接测试。
- 流式与非流式回复，思考过程折叠，长度截断与断流提示。
- 本机 IndexedDB 保存，图片压缩，对话/图片/提示词 JSON 导入导出。
- 浅色/深色/跟随系统，iOS 安全区域和键盘视口，主屏幕图标和 PWA。
- 浏览器直连 / 同源或独立服务端代理，私人访问口令、请求上限、超时、公网 DNS 校验与固定解析地址、不跟随重定向。无自动收费重试。

联网搜索、云同步、语音、原生 iOS 安装包不在这一版中。

## 固定的手机网址（GitHub Pages 版）

固定入口：<https://agbird1321939012-design.github.io/jianwei-vision-chat/>

这一版本直接在 iPhone 浏览器中调用你填写的中转站，不依赖电脑持续开机。打开网页后填写 URL、密钥、模型名称并保存即可。安装到主屏幕后再配置 API 更稳妥。

**中转站必须允许浏览器跨域调用（CORS）。** 如果连接测试提示直连失败，且 URL、密钥和网络均正确，可在“设置 → 连接方式”改为“使用代理”，填写运行本项目服务端的 HTTPS 网址和访问口令。代理可以用下方 Docker、Render 或 Vercel 部署；临时体验代理需电脑保持运行。

这里不会自动重试或把密钥发送给公共第三方 CORS 代理。直连时密钥仅发送至你填写的中转站；代理模式则经你选定的私有代理转发。

GitHub Pages 托管的是公开应用文件，API 密钥和对话不上传到 GitHub。源码仓库也不包含你的密钥。部署工作流只编译静态文件；同一份源码同时保留完整 Node 服务端版本。

## 在电脑本机启动

安装 **Node.js 22.12 或更新版本**，在这个文件夹打开终端：

```sh
npm ci
npm run dev
```

打开 <http://127.0.0.1:5173>。网页右上角点“选择你的模型”进入设置，填写：

1. API URL，例如 `https://你的中转站/v1`。也接受根地址或完整 `/chat/completions` 地址。支持 HTTPS 443 端口。
2. API 密钥。
3. 中转站提供的完整模型名称。模型是否能识图由实际接口决定，不能根据名称推断。

点击“发送连接测试”验证文本连接；这是真实 API 调用，可能计费。再发送一张测试图片验证识图。**连接测试成功不代表图片能力已经确认。**

不勾选“在本机记住密钥”时，密钥只保留在当前页面内存中，刷新需重填；勾选后，密钥和私人访问口令一起存入当前设备浏览器。清除输入并保存可删除已保存的密钥。

## 让 iPhone 真正使用

**推荐：部署到有 HTTPS 的固定网址，然后在 iPhone 的 Safari 打开。** 手机会独立访问在线服务，无需电脑开机。不要把电脑的 `localhost` 发给手机——那不是手机可以访问的地址。

### 方式 A：Render / Docker（适合多图和长对话）

项目包含 `Dockerfile` 和 `render.yaml`。将源码放入你自己的 Git 仓库，在 Render 创建 Blueprint，选择该仓库。配置中会生成 `ACCESS_PASSWORD` 私人口令，可在服务的 Environment 中查看或自行设置。部署完成后，打开 Render 分配的 HTTPS 域名。

也可在任何支持 Docker 的服务器部署：

```sh
docker build -t jianwei .
docker run --rm -p 5173:5173 -e ACCESS_PASSWORD='换成你的长口令' jianwei
```

服务器需要用反向代理提供 HTTPS。公开服务务必保留私人口令。Render 免费实例可能休眠，第一次打开会较慢；是否提供免费套餐以平台为准。

### 方式 B：Vercel（部署简便）

1. 将源码放入你自己的 Git 仓库，在 Vercel Import Project，导入这个文件夹作为项目根目录。
2. 使用 Vite 框架，Build Command 为 `npm run build`，Output Directory 为 `dist`。项目包含函数 `api/[...path].ts`，不要仅上传静态 `dist` 文件夹。
3. 在 Environment Variables 添加 `ACCESS_PASSWORD`，填你自己的私人访问口令，然后部署。
4. 打开分配的 HTTPS 域名，在 API 设置中输入该口令，再填写中转站配置。

也可在此目录运行 `npx vercel` 按提示登录并部署。当前不会替你创建账号、公开 Git 仓库或上传真实密钥。

Vercel 的函数请求体有约 4.5 MB 平台上限，因此本项目在该环境会提前以 3.9 MB 检查请求，避免图片和历史内容超过上限。大量图片或长对话更适合 Docker/Render。函数执行时长受平台套餐限制，超过平台限制会中断。

### iPhone 添加到主屏幕

1. **先部署 HTTPS，再用 Safari 打开该网址。**
2. 点 Safari 的“分享”按钮。
3. 选择“添加到主屏幕”，按版本提示启用“作为网页 App 打开”，再点“添加”。
4. 从新图标打开见微，再填写 API 配置。

建议 iOS 17 或更新版本。测试包含 Playwright WebKit 的 iPhone 尺寸仿真；真实设备上的相册、相机权限、键盘、HEIC 解码和安装过程仍需真机确认。界面布局仿真不能代替这一步。

iPhone 点击输入框时可正常换行，点箭头发送；外接键盘支持 Command/Ctrl + Enter。电脑 Enter 发送、Shift + Enter 换行，中文输入法选词不会误发送。

### 临时体验与局域网

如果收到临时 HTTPS 体验地址，可以马上在 iPhone Safari 打开并填写私人访问口令。**临时地址需要这台电脑和转发进程保持运行，地址可能失效；它不等于固定云部署。**

同一 Wi-Fi 临时测试可复制 `.env.example` 为 `.env`，填写 `ACCESS_PASSWORD` 并把 `HOST` 改为 `0.0.0.0`，重新启动，再在手机打开 `http://电脑局域网IP:5173`。Windows/WSL 的防火墙或端口转发可能需额外配置；HTTP 不适合正式安装 PWA。优先使用 HTTPS 方式。

## 数据与使用边界

- 聊天、图片、提示词保存在**当前设备、当前网址、当前浏览器**。不会自动在电脑与 iPhone 间同步。Safari 网页和主屏幕 App 的数据容器也不应假定完全共享：先安装，再配置更稳妥。
- 更换网址、浏览器、临时域名或设备前，去“设置 → 数据”导出 JSON，然后在新环境导入。备份包含图片和文字，默认不含任何连接设置、API 密钥或访问口令。
- 系统清理浏览器数据或存储不足可能删除记录；PWA 离线缓存不是永久备份。可以离线查看已保存的记录，生成回复始终需要联网。
- 单条消息最多 6 张图，单个原文件最多 30 MB，压缩为 JPEG，最长边可选 1024/1600/2048。原图不改动。浏览器无法解码的 HEIC 等文件请先转为 JPEG/PNG；并非所有 Safari 版本都支持同样的图片格式。
- 每次请求最多 200 条上下文消息，超过容量会明确提示减少图片或新建对话。所有历史图片都会随上下文发送，因此也会占接口配额。
- 生成时保持应用在前台。iOS 后台冻结、锁屏和网络切换可能断开请求；已收到的文字会保留，不会自动重试产生费用。
- 直连模式只向中转站发送请求；代理模式经过你选择的代理以及中转站。本项目服务端不把聊天、密钥和图片写入数据库或应用日志；托管平台仍可能记录请求元数据。代理请求只转发到公网 HTTPS 服务。
- 默认兼容 OpenAI Chat Completions 的 `text` / `image_url` 消息和常见 DeepSeek 风格 `reasoning_content`。其他协议需要新增适配。
- 自建界面没有额外的关键词过滤。中转站和模型自身的拒答、审核、截断、计费限制仍然存在。
- 程序不内置模型，也不赠送 API 配额。测试接口通过不能证明真实中转站或某个 DeepSeek 模型可用。

## 生产运行与验证

```sh
npm test
npm run build
npm start
```

`.env` 会被启动命令自动读取，部署平台也可直接注入环境变量。

| 变量 | 作用 |
| --- | --- |
| `ACCESS_PASSWORD` | 公网/局域网访问口令，客户端填写于 API 设置 |
| `HOST` | 默认 `127.0.0.1`；容器使用 `0.0.0.0` |
| `PORT` | 默认 `5173`，平台可自动分配 |
| `APP_PUBLIC` | 设置 `1` 会要求访问口令；Vercel 和 `HOST=0.0.0.0` 也会自动要求 |
| `PUBLIC_ORIGIN` | 可选的固定 HTTPS 来源，允许该网站跨域调用代理 |
| `DNS_MODE` | 可选 `cloudflare`，使用 HTTPS DNS 解析并校验公网 IP；默认系统 DNS |

平台未配置口令时，公开模式会禁止 API 转发。跨站调用仅允许匹配 `PUBLIC_ORIGIN` 的固定网站；例如 GitHub Pages 使用 `https://agbird1321939012-design.github.io`（不带路径）。服务端会拒绝本机/内网/特殊地址及重定向，并将 DNS 解析结果固定到实际连接，防止解析后变更目标。

生产版不使用外部字体、统计脚本或 CDN 资源。Markdown 不渲染 HTML，也不会自动加载模型回答里引用的远程图片。

源码模块分别负责 UI、存储、图片处理、流式解析与代理，具体入口为 `src/App.tsx` 和 `server/index.ts`。
